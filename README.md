# -JPEG-LS-encode
 该项目实现了 JPEG－lossless （符合 ITU－T T。87 协议）模式的图片编码。图像按 pixel 从 handshake 接口输入，编码码流按 byte 从 handshake 接口输出。支持 8 bit 解析度的黑白或 RGB 图像。
 
流水线控制：使用 8 级流水线实现压缩算法，构建 Run 与 Normal 模式的双数据通路。使用 vld ／ ack 处理数据冲突。针对读写同址，引入 Forwarding 机制直接旁路取数，针对强数据依赖，设计 Stall 机制暂停流水线。

算法优化： 设计读地址绕回 Pre＿fetch 机制，使用单端口 SRAM 实现行缓存，并掩盖了跨行读取延迟，设计读写指针错位机制，解除同时进行读写的需求。支持编码数据流 100％吞吐率的同时大幅缩减面积开销。

功能验证： 结合 C Model 与 verilog 搭建的仿真环境，对多组图片进行仿真，打印出每级流水线的结果进行自动比对。

项目成果： 该模块的平均处理能力为 0.91 pixel ／ cycle。在基于 TSMC 0.13 um 工艺下频率可以达到 150 Mhz。可实现编码1920＊1080＊ 60 fps 灰度图片的需求。
